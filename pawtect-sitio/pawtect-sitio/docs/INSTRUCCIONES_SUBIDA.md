# Cómo aplicar esta actualización al repositorio

Este ZIP es un **paquete de actualización documental**, no una copia completa del repositorio.

## Destino exacto

Descomprime el contenido en la raíz del repositorio `Milioafk/paw_tect`, rama `actualizacion-plataforma`, conservando la estructura de carpetas.

Los cuatro documentos nuevos deben quedar en:

`pawtect-sitio/pawtect-sitio/docs/`

## Después de subir

1. Comprueba que aparezcan los cuatro archivos Markdown dentro de `docs`.
2. Haz commit con el mensaje: `docs(pawtect): agrega protocolo Modelo A, prevención, FAQ y roadmap`.
3. No reemplaces archivos de código, SQL, variables de entorno ni secretos con este paquete.
4. La guía `pawtect-sitio/pawtect-sitio/GUIA.md` todavía debe recibir enlaces a estos cuatro documentos.
5. Esta entrega no cambia la aplicación ni activa WhatsApp, una línea telefónica o denuncias anónimas. Esas funciones requieren desarrollo y validación antes de anunciarse.
